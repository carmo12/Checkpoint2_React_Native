# 🛒 CheckPoint 2 - Lista de Compras

Aplicativo mobile desenvolvido em **React Native** utilizando **Expo**, como parte do segundo CheckPoint da disciplina de Cross-Platform Application Development.

O projeto tem como objetivo praticar o uso dos componentes **FlatList** e **TextInput**, juntamente com o gerenciamento de estado utilizando **useState**.

## 📱 Sobre o projeto

O aplicativo permite criar e gerenciar uma lista de compras de forma simples.

O usuário pode:

- Adicionar um novo item;
- Informar a quantidade desejada;
- Visualizar os itens adicionados;
- Excluir itens da lista;
- Visualizar a quantidade de itens cadastrados.

## 🚀 Funcionalidades

### ➕ Adicionar item

O usuário informa:

- Nome do produto;
- Quantidade.

Ao clicar em **Adicionar**, o item é inserido na lista.
